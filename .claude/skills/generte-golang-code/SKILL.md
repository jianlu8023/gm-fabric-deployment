# generate-golang-code-guide

这是一个专门用于生成golang代码的技能，它可以帮助你快速生成各种golang代码，包括但不限于函数、结构体、接口、常量、变量等。

## 场景与代码建议对应关系

| 场景 | 代码建议 |
| golang+gin+gorm的web开发 | web-module-guide |

## 使用案例

1. 帮我生成一个用户登录相关的功能
2. 我需要一个golang的http请求函数

## 注意事项

- 请确保你已经在你的项目中安装了golang语言环境。
- 请确保你已经在你的项目中安装了gin和gorm库。
- 请确保你已经在你的项目中安装了相关的依赖库。
- 每一步都需要按照 思考->生成文档->执行->生成文档->测试->生成文档->反思与总结->生成文档 的流程进行。
