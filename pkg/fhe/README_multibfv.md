# 多方BFV同态加密实现说明

本文件实现了基于BGV方案的多方同态加密计算，支持多个参与方协作进行安全计算。

## 实现步骤

### 第一步：环境准备和参数设置
1. 导入必要的包：`lattigo/v6`系列库
2. 设置BFV参数：
   - LogN: 13 (环度)
   - LogQ: []int{55, 54, 54} (密文模数)
   - LogP: []int{55} (辅助模数)
   - PlaintextModulus: 0x10001 (明文模数)
3. 定义参与方数量(N=3)和阈值(t=2)

### 第二步：参与方生成和密钥初始化
1. 调用`genParties`函数创建N个参与方
2. 为每个参与方生成：
   - Shamir公共点
   - 私钥
   - 输入值(示例中所有参与方输入均为1)

### 第三步：阈值密钥生成
1. 创建Thresholdizer实例
2. 为每个参与方分配份额内存
3. 各参与方生成Shamir多项式并分发份额
4. 每个参与方聚合收到的份额

### 第四步：集体公钥生成
1. 创建公共参考字符串(CRS)
2. 执行集体密钥生成协议(execCKGProtocol)
3. 生成集体公钥用于后续加密操作

### 第五步：集体重线性化密钥生成
1. 执行集体重线性化密钥生成协议(execRKGProtocol)
2. 生成重线性化密钥用于处理乘法运算后的密文

### 第六步：输入加密
1. 创建编码器和加密器
2. 每个参与方将自己的输入编码并加密
3. 生成加密的输入密文

### 第七步：同态计算
1. 创建评估器用于同态运算
2. 执行同态加法运算(1+1+1)
3. 执行同态乘法运算(1*1*1)，并进行重线性化处理

### 第八步：集体解密
1. 选择t个在线参与方进行解密操作
2. 执行集体密钥切换协议(execCKSProtocol)
3. 使用零私钥解密结果
4. 解码并验证计算结果的正确性


## 安全特性

- 使用Shamir秘密共享保证密钥安全
- 阈值方案确保即使部分参与方离线也能完成计算
- 集体密钥生成避免单点故障
- 支持加法和乘法同态运算
