# 阈值同态加密方案说明

本文件实现了阈值同态加密方案的分析和示例，包括多方参与的阈值方案和阈值参数分析。

## 实现步骤

### 第一步：阈值方案分析
1. 定义ThresholdAnalysis结构体，包含总参与方数(N)和阈值(t)
2. 实现安全级别计算方法(可容忍的敌手数量 = t-1)
3. 实现可用性级别计算方法(可容忍的故障数量 = N-t)
4. 实现效率指标计算方法(参与操作的最小参与方比例 = t/N)

### 第二步：阈值方案示例
1. 设置总参与方数(N=100)
2. 定义多种t值设置进行分析(2, 10, 25, 34, 50, 67, 75, 90, 99)
3. 对每种t值设置进行分析：
   - 计算安全级别
   - 计算可用性级别
   - 计算效率指标
   - 计算安全边际

### 第三步：多方参与阈值方案示例
1. 设置BFV参数(LogN=12, 简化参数以加快演示速度)
2. 创建100个参与方
3. 分析不同的t值设置(2, 25, 50, 75, 99)
4. 对每种设置模拟阈值密钥生成
5. 随机选择在线参与方进行操作
6. 显示安全性和可用性指标


## 关键概念

### 阈值方案定义
- **N**: 总参与方数
- **t**: 阈值(操作所需的参与方数量)
- **安全级别**: 可容忍的敌手数量(t-1)
- **可用性级别**: 可容忍的故障数量(N-t)
- **效率指标**: 参与操作的最小参与方比例(t/N)

### 推荐设置
1. **t=50 (50%阈值)** - 安全性与可用性的最佳平衡
2. **t=34 (34%阈值)** - 更高可用性，适合对可用性要求高的场景
3. **t=67 (67%阈值)** - 更高安全性，适合对安全性要求高的场景

## 安全特性

- 基于Shamir秘密共享的阈值方案
- 可调节的安全级别和可用性级别
- 支持大规模参与方(示例中100个)
- 随机选择在线参与方模拟实际场景
