# 单方BFV同态加密实现说明

本文件实现了基于BGV方案的单方同态加密计算，适用于单个实体进行安全计算。

## 实现步骤

### 第一步：环境准备和参数设置
1. 导入必要的包：`lattigo/v6`系列库
2. 设置BFV参数：
   - LogN: 13 (环度)
   - LogQ: []int{55, 54, 54} (密文模数)
   - LogP: []int{55} (辅助模数)
   - PlaintextModulus: 0x10001 (明文模数)
3. 创建参数实例并检查错误

### 第二步：密钥生成
1. 创建密钥生成器(KeyGenerator)
2. 生成私钥(SecretKey)
3. 生成重线性化密钥(RelinearizationKey)

### 第三步：编码器、加密器和解密器初始化
1. 创建编码器(Encoder)用于明文和多项式之间的转换
2. 创建加密器(Encryptor)用于明文加密
3. 创建解密器(Decryptor)用于密文解密

### 第四步：数据准备
1. 创建两个输入向量(values1和values2)
2. 设置向量值(示例中设置为100和200)
3. 显示明文模数和向量的前几个值

### 第五步：编码和加密
1. 创建明文实例
2. 使用编码器将向量编码为明文
3. 使用加密器将明文加密为密文

### 第六步：同态运算
1. 创建评估器(Evaluator)用于同态运算
2. 执行同态加法运算(ct1 + ct2)
3. 执行同态乘法运算(ct1 * ct2)
4. 对乘法结果进行重线性化处理

### 第七步：解密和结果验证
1. 使用解密器解密运算结果
2. 使用编码器解码明文
3. 计算期望结果用于对比
4. 打印实际结果和期望结果
5. 验证运算正确性




## 特性

- 支持加法和乘法同态运算
- 使用scale-invariant BGV方案
- 自动重线性化处理
- 结果精度验证
- 128位安全级别
